# 英语随手练

手机浏览器打开一节约 5 分钟的课。先听一句并核对原文，再跟读短句，最后换场景开口。内容从酒店、交通和 Java 工作沟通起步。已练标记保存在当前设备。

## 本地试用

用 Node.js 24 运行 `npm run build`。打开 `dist/preview.html` 可直接试用酒店首课和内置音频。运行 `npm run preview` 可通过终端打印的本地地址检查站点及写入逻辑。预览数据库只在本次进程中保存。

首课使用英语合成 WAV，网页按需加载并支持分段读取。新课的英语文本由设备朗读。浏览器没有英语语音时仍可查看原文。

## 发布与每日更新

网站采用 Sites 私有访问。发布后先验证 D1 迁移、移动端登录和首课音频，再通过 Site 提供的课程工具验证无人值守的读写。首次创建站点后把返回的站点 ID 写入 `.openai/hosting.json`，源代码只提交到该站点的专用仓库。

每日任务使用北京时间。先调用 `read_daily_english` 取得日期、今日状态和最近课题。若当天已有课则结束。否则在旅行和 Java 工作沟通之间轮换，写一段听力、三至四句中英跟读和一道换情境的开口题。优先从酒店、交通、面试自我介绍、日会和确认需求出题。句子宜短，工作情境只用已确认的背景或明确写成演练。调用 `publish_daily_english` 后读回当天课程。同日重试保留先前已写入的版本。

每次更新只写课程数据。建议时刻为北京时间 07:00，待发布及写入验证后创建关联定时任务。
